# Publish or request publish (`org.rd.plugin.uigoodies.PublishOrRequestPublish`)

Toolbar control for **publish** or **request publish** flows, depending on permissions and site setup.

## Configuration

```xml
<widget id="org.rd.plugin.uigoodies.PublishOrRequestPublish">
    <plugin
            id="org.rd.plugin.uigoodies"
            site="{site}"
            type="apps"
            name="uigoodies"
            file="index.js"
    />
    <configuration>
        <useIcon>true</useIcon>
    </configuration>
</widget>
```
