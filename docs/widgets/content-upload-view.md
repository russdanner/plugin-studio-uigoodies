# Content upload view (`org.rd.plugin.uigoodies.ContentUpload`)

**Embedded** upload UI used inside the dialogs opened by [openContentUploadPanelButton](open-content-upload-panel-button.md) and [openContentUploadToolbarButton](open-content-upload-toolbar-button.md). You normally do **not** add this widget to `ui.xml` yourself unless you are composing a custom dialog.

Registered so Studio can resolve the widget when the open buttons dispatch the upload dialog.
